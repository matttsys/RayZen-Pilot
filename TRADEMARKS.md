# Name and logo policy

The code is licensed under AGPL-3.0 (see `LICENSE`). This page is only about the **name** “RayZen”, “RayZen Pilot” and the RayZen logo. It does not restrict anything the license allows.

**You may**

- fork, modify, run and redistribute the code under AGPL-3.0;
- say your project is “based on RayZen Pilot” or “a fork of RayZen Pilot”, with a link to https://github.com/matttsys/RayZen-Pilot;
- use the name to refer to the original project accurately.

**Please don't**

- publish a modified bot or package under the name “RayZen” or “RayZen Pilot”, or with the RayZen logo, in a way that makes people think it is the official project or endorsed by it;
- use the logo as the avatar of a bot you run, unless it is the unmodified official release.

If you fork, pick your own bot name and avatar, and keep the attribution in `NOTICE`.

This is a request about naming, not a legal guarantee or extra license condition. Questions: open an issue at https://github.com/matttsys/RayZen-Pilot/issues.

**مجاز است:** فورک، تغییر، اجرا و انتشار دوباره طبق AGPL-3.0؛ و نوشتن «بر پایهٔ RayZen Pilot» با لینک به مخزن اصلی.

**لطفاً نکنید:** انتشار نسخهٔ تغییریافته با نام یا لوگوی RayZen به شکلی که رسمی یا تأییدشده به نظر برسد. برای فورک، نام و تصویر ربات خودتان را انتخاب کنید و انتساب را در `NOTICE` نگه دارید.
